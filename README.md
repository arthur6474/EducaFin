# EducaFin
O EducaFin promove a educação financeira entre estudantes do ensino médio. Com quizzes, desafios, simuladores e gamificação, ensina orçamento, poupança, consumo consciente e planejamento financeiro de forma interativa e acessível, ajudando jovens a tomar decisões mais sábias no dia a dia. A plataforma torna o aprendizado prático e útil para a vida.
